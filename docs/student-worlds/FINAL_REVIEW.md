# 학생 그림 3D 월드 20개 최종 검수·성찰

검수일: 2026-09-05
대상: `start.jpg` 20개와 해당 3D 월드. `end`·영상은 사용하지 않았다.

## 전체 판정

> 공개 전 정정: 20개 장면의 기본 입력 검증과 원본 성찰은 수행했다. 그러나 모든 스토리 목적지까지 실제 조작으로 왕복하거나 모든 발판의 착지를 확인한 것은 아니다. 아래 구조 접근성 자동 검사는 일부 단순화·복제 메시와 높이 조건 검사이므로 실제 장면 전체의 접근성을 보증하지 않는다. 현재 공개 단계는 탐험 프로토타입이다.

- 제작: 20/20 장면·설정·원본 보기·테마 네비게이션 연결 완료.
- 원본 무결성: 공개된 20개 `start.jpg`가 원본 폴더의 파일과 SHA-256 기준 모두 일치한다.
- 자동 검증: 공통 이동·2단 점프·3번째 점프 차단·착지 재충전·측면/머리 충돌·가장자리 낙하·수영 왕복·미끄럼틀·20개 카탈로그/목적지/원본·설빙 정상·16번 세 시설·03번 보트·택시 지붕·다보탑 상층 검사가 31/31 통과했다.
- 실제 화면: PC Chrome에서 20개를 테마 선택기로 순차 전환해 모두 `탐험 중` 상태, 정확한 제목, 4000px 원본 이미지 로딩을 확인했고 오류 로그는 0건이었다. 이어 20개 모두 화면 방향 버튼의 실제 누름으로 좌표 변화를 확인했다. 건조 시작 월드는 두 번 점프해 높이 상승을, 수중 시작 월드는 수영 상태와 힘차게 젓기 입력을 확인했다. ID10의 유일한 이동 실패는 시작점 경계를 수정한 뒤 재검사해 통과했다.
- 한계: 실물 태블릿의 실제 멀티터치와 장시간 FPS는 별도 기기가 없어 미검증이다. 390×844 Chrome 뷰포트의 UI 렌더는 확인했다.

## UI/UX 검토와 반영

- 유지: 테마 드롭다운, 이전/다음, 원본 보기, 초기화, 미니맵, 이동·점프·시점 버튼. 20개 사이에서 길을 잃지 않고 원본과 즉시 비교하는 데 필요하다.
- 제거/수정: 미니맵 아래 개발자용 숫자 좌표는 시각적으로 숨겼다. 목록의 `3D 시범작`, `하나씩 만들고 있어요` 문구는 20개 완성 상태에 맞게 바꿨다.
- 확인: 화면 방향·시점 버튼은 길게 누르는 동안 움직이고 손을 떼면 해제되는 방식이다. 짧은 마우스 클릭은 이동량이 거의 없어 도움말에 `길게 누르기`를 명시하는 편이 낫다.
- 수정: 11번 지도에서 경계 밖이던 붉은 배 표식을 접근 가능한 `붉은 배 보기` 지점으로 옮겼다.
- 수정: 390×844 실제 렌더에서 미니맵 라벨이 겹치는 것을 확인해 520px 이하에서는 미니맵을 숨겼다. PC에서는 핵심 장소 안내에 유용해 유지했다. 검수 캡처는 `screenshots/mobile-390x844.png`.

## 착지·접근성 판정

- 공통 물리: 2단 점프, 3번째 차단, 착지 후 재충전, 옆면·머리 충돌, 가장자리 낙하를 자동 검증했다.
- 물: 08·19·06·09·13·16·03은 물 영역을 갖고, 입수/부유/육지 복귀 또는 접근 계단을 작품 설정과 테스트로 구분했다.
- 핵심 목적지: 20개 모든 지도 목적지가 이동 경계 안에 있음을 자동 검증했다. 18번은 실제 달 곡면 높이에 시작점과 이동 바닥을 맞췄다.
- 고위험 접근: 05번 설빙·16번 세 시설·03번 보트는 실제 메시 연속 이동 검사를 통과했다. 14번 택시는 차체→운전석→지붕 표지 단계 착지, 01번 다보탑은 정면 계단과 상층 점프 간격 검사를 통과했다.

## 추가 기기 검증

- PC 기준 제작·원본 성찰·기본 실제 입력 검수는 수행했다. 전체 목적지 왕복·모든 발판 접근성 검수는 남아 있다.
- 실물 태블릿이 준비되면 이동+시점 동시 누름, 손을 뗀 뒤 정지, 장시간 성능을 추가 확인한다. 이는 이번 PC 완료 판정과 구분한다.
