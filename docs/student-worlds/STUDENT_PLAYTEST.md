- 제작 7 / ID03 아쿠아리움: 부두에서 물로 들어가면 z≈-2.2, 높이≈-0.76에서 멈췄다. 점프로 넘으면 수면 위를 걷게 됐다. 물 장식의 두꺼운 메시가 발판으로 등록된 것이 원인이다. 장식 바닥을 낮추고 발판에서 제외했으며, 부두 끝과 수면 경계를 지면 판정에 맞췄다. 수면은 물속 생물이 보이도록 반투명으로 변경했다.

두 오류는 수정 전 실제 브라우저와 실제 JSX 메시 기반 자동 검사에서 모두 재현했고, 수정 후 자동 검사가 통과했다.
