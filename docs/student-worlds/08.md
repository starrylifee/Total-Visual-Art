## 후속 개선: 점프와 상하 시선 (2026-09-05)

### 최신 개선: 공통 관절 캐릭터와 주변 인물 (2026-09-05)

- `Character.jsx`를 공통 캐릭터로 분리했다. 어깨→팔꿈치→손, 골반→무릎→발의 관절 계층, 둥근 몸통·귀·앞머리·눈 하이라이트·볼·입·손가락·신발·옷의 연필 질감을 구현했다.
- 걷기·수영·공중 점프·착지 자세를 물리 상태와 연결하고 각도 전환을 보간한다. 착지할 때 몸을 잠깐 낮춘다. 원본 보기 중 조종 캐릭터 애니메이션은 멈춘다.
- 주변 인물은 머리색·피부색·하의·묶은 머리를 달리하고, 가게 앞 대화하는 무리, 손 흔드는 사람, 모래성 만드는 사람, 돗자리 옆과 바다의 앉은 사람, 누워 쉬는 사람으로 구성했다. 쉬는 사람은 얼굴이 위로 향하도록 방향을 수정했다.
- 인물마다 움직임의 시차가 있으며, 눈 깜빡임·호흡·고개 움직임이 있다. 가까운 아바타를 바라보는 고개 회전을 추가했다. 대화는 몸짓 표현이며 대화 AI나 음성은 없다.
- Windows Chrome에서 장면 전체와 아바타 정면 렌더를 확인, 오류 로그 없음. 빌드 및 기존 물리 회귀 테스트 13/13 통과. 캡처: `screenshots/08-characters.png`.
- 한계: 학생 원본 인물을 개별 조각한 정확한 복원이나 모션캡처 캐릭터는 아니다. 손그림 색감을 참고한 관절 메시이며, 실제 태블릿 성능·전체 수영 모션 검수는 남아 있다.

### 최신 개선: 바다 수영 (2026-09-05)

- 바다 쪽 이동 범위를 z=-34까지 확장했다. 해안 z=-8.5부터 부드럽게 몸이 잠기고, 깊어진 곳에서는 수영 자세로 전환된다. 수면 부근에 떠 있고 해변으로 돌아오면 다시 걷는다.
- 몸 기울이기, 양팔 젓기·발차기, 수면의 가벼운 흔들림과 원형 물결을 추가했다. 수영 속도는 걷기보다 느리고 Space/“힘차게” 버튼으로 0.7초간 빠르게 헤엄친다.
- 물과 움직이는 돌고래는 고정 발판 계산에서 제외했다. 육지의 2단 점프·사물 착지는 유지한다. 물속 바닥은 부력 처리를 위한 가상 높이이며 잠수 기능은 없다.
- 지도에 바다 탐험 범위를 반영하고, 수영 상태 안내·버튼 문구를 연결했다.
- 테스트 13/13 통과: 모래 지형을 포함한 해안 진입·부유·육지 복귀, 공중에서 물로 떨어질 때 부유 전환, 먼바다 경계 및 기존 발판·2단 점프 회귀 검증. 최종 빌드 통과.
- 브라우저에서 최신 장면·안내 렌더를 확인했다. 실제 수영 조작과 실물 태블릿에서의 시각·입력 검수는 후속 확인 대상이다.
- 이전 기록의 “바다는 관찰 대상이며 수영 기능 없음”은 이 변경으로 대체된다.

### 추가 개선: 2단 점프와 물체 위 착지

- 후속 요청으로 기존 1회 점프를 2단 점프로 교체했다. Space/점프 버튼을 각각 눌러 지상 1회 + 공중 1회 점프한다. 착지 시 횟수가 초기화되고, 가장자리에서 걸어 떨어지면 공중 점프 1회가 남는다.
- `platformPhysics.js`와 `platformSurfaces.js` 추가. 발 주변 5곳의 수직 광선으로 실제 메시의 윗면·아랫면을 읽어 착지·측면·머리 충돌을 처리한다. 작은 곡면 변화는 걸어서 이동한다.
- 튜브 곡면, 가게 카운터·간판, 모래성, 파라솔, 돗자리·식기 및 낮은 울타리 등 고정 물체를 발판으로 표시했다. 사람과 바다의 움직이는 대상은 탐험 발판으로 취급하지 않는다. 바다·맵 경계는 유지한다.
- 높은 물체는 옆에서 점프해 윗면으로 접근한다. 파라솔 바로 아래에서 뛰면 천막 아랫면에 머리가 닿는다. 튜브의 빈 중심은 채워진 원기둥으로 처리하지 않으며, 가느다란 물체는 발 위치를 맞춰야 한다.
- 카메라는 올라간 높이를 따라간다. 발밑 원은 실제 지지 표면 위에 표시한다. 위치 초기화 시 2단 점프 횟수도 복원한다.
- 테스트 총 11/11 통과: 3번째 점프 차단, 착지 후 재충전, 상자 측면에서 뛰어올라 착지, 발판 가장자리 낙하, 머리 충돌, 파라솔 높이에 도달 가능한 2단 점프, 실제 상자·튜브 메시 표면과 중심 구멍 판정. 빌드 통과.
- 아래 1회 점프·수평 충돌 관련 내용은 이전 버전의 기록이며 이 추가 개선이 최신 동작이다.

- 사용자 피드백에 따라 Space/화면 점프 버튼, I/K 및 세로 드래그/위·아래 버튼을 추가했다.
- 점프 높이는 약 1.2, 체공 시간은 약 0.78초. 이동 중에도 점프 가능하며 공중 재점프는 막는다. 장애물의 기존 수평 충돌은 유지한다.
- 카메라 상하 각도를 제한하고 카메라가 지면 아래로 내려가지 않게 했다. R/처음 위치로 실행 시 높이·점프 속도·시선 각도까지 초기화한다.
- 원본 비교 모달에서는 점프도 정지하며 대기 중 입력을 비운다. 착지하면 지면 높이로 정확히 복귀한다.
- 이동·점프·각도 제한 테스트 6/6 통과, 빌드 통과. Chrome에서 점프의 공중 프레임과 위쪽 시선 변경을 확인했고 오류 로그는 없었다.
- [점프·상하 시선 캡처](screenshots/08-jump-look.png)
- 실물 태블릿의 동시 터치 검증은 기존과 같이 남아 있다. 사용자는 그 외 시범작 구성에 긍정적인 피드백을 주었다.

## 새로 설계한 부분

- 종이의 평면 배치를 깊이가 있는 해변으로 해석했다. 가게·튜브·파라솔·모래성은 뒤로 돌아볼 수 있는 입체 메시다.
- 아바타는 공통 탐험용 캐릭터이며 학생이 그린 특정 인물의 정확한 3D 복원이 아니다.
- 가게 뒷면·카운터 깊이, 물체 사이 이동 공간, 바깥 모래사장과 낮은 줄 울타리는 제작자가 보완했다.
- 탐험 영역은 대략 x -14~14, z -6.8~15. 바다는 관찰 대상이며 수영 기능은 없다.
- 튜브는 안정적인 충돌 처리를 위해 중심 구멍까지 포함한 원형 경계를 쓴다. 모래 위 돗자리는 걸어갈 수 있다.
- 원본 선과 색을 참고해 코드로 만든 연필 획 질감을 적용했다. 원본의 필치를 직접 입체 표면에 투영한 것은 아니다. 간판 글씨는 코드로 다시 썼다.
- 파도·돌고래에 가벼운 반복 움직임을 추가했다. 배경 사람은 단순화했다.

## 검증 결과

- `npm run build`: 최종 코드 통과. 기존 Firestore 정적/동적 혼용 및 500kB 초과 청크 경고는 남음. 신규 탐험 화면과 3D 장면은 지연 로딩된다.
- `node --test src/features/student-worlds/movement.test.mjs`: 4/4 통과. 입장 위치·네 방향 경계, 큰 이동량에서도 가게/튜브 관통 방지, 벽 따라 미끄러짐, 대각선 속도·카메라 상대 방향 확인.
- `git diff --check`: 통과. 줄바꿈 변환 안내만 출력.
- Windows Chrome 실제 렌더 확인. 브라우저에서 신규 기능의 error 로그 없음. React Router의 기존 future flag 경고는 있음.
- 20개 목록 표시, 대기 중 19개 비활성, 해변 입장·목록 복귀·재입장 확인.
- 이동 버튼의 키보드 Space 조작으로 위치가 `0.0 / 11.0` → `0.0 / 10.4` → `0.6 / 10.4`로 변함을 확인. 초기화 후 `0.0 / 11.0` 복귀.
- 캔버스의 실제 포인터 드래그로 카메라가 회전하고 사물의 옆면이 보이는 것을 캡처로 확인.
- 원본 비교 모달 표시·이미지 로딩·Escape 닫기·모달 중 이동 정지 확인.
- PC 기본 화면과 1024×768 화면의 시각 검수. 390×844는 DOM에서 화면 너비와 버튼 배치를 확인했지만 최종 스크린샷 촬영이 시간 초과되어 시각 검수 완료로 간주하지 않음.
- 길게 누르기 자동화가 브라우저 제어 시간 제한으로 중단됨. 실제 태블릿 멀티터치·장시간 눌렀다 떼기·물리 키보드 연속 이동은 후속 기기 검증에 남긴다.
- PC·태블릿 FPS와 메모리 장시간 실측은 하지 않았다. 성능 수치를 보장하지 않는다.
